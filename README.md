I'm an instrumentation and control engineering student at NIT Jalandhar. I build full-stack web apps, systems software, and embedded projects that have to run on real hardware.

Currently pursuing a B.Tech in Instrumentation and Control Engineering. Most of my time goes into TypeScript on the web, C++ when the problem is a storage engine or a tight loop, and Python on the device.

I work across React, Node.js, and Express, with MongoDB and PostgreSQL behind them, and I deploy on Linux with Docker, Nginx, and AWS. On the hardware side I use Arduino and Raspberry Pi, including camera pipelines and models that run on the board.

## Projects

[**MedTech**](https://github.com/Pradeep-gif-hub/MedTech) is a telemedicine kiosk. A clinic books a remote consult and keeps records and prescriptions in one place.

[**ForgeDB**](https://github.com/Pradeep-gif-hub/ForgeDB) is a transactional storage engine in C++20. Fixed-size pages, a buffer pool, a B+ tree, write-ahead logging, and ARIES recovery.
